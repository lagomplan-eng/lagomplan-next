Follow-up: World Cup pages (/es/mundial/cdmx)

The 17 World Cup files named Manrope/Fraunces directly and loaded them from Google at runtime (an @import in each page). They now use var(--font-sans) / var(--font-display) and the @import is removed, so the pages use the same self-hosted fonts as the rest of the site. Google Fonts requests on this page: before 4 (fonts.googleapis.com, fonts.gstatic.com), after 0. Visible difference: very small. The self-hosted Fraunces has weights 500/600 (the old import also had 400/700/900), so a few heavy serif weights render one step lighter.
